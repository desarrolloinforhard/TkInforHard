# Shadows

Tkinter/ttk no ofrece sombras nativas consistentes.

Estrategia:

- Simular profundidad con contraste de superficies.
- Usar bordes suaves.
- Reservar sombras reales para futuras implementaciones con Canvas, imagenes o wrappers especificos.

Las cards actuales usan superficies diferenciadas y padding para crear jerarquia visual.
