# Radius

Los radius se definen en `TkInforHard/theme/radius.py`.

Tokens:

- `RADIUS_SM = 6`
- `RADIUS_MD = 12`
- `RADIUS_LG = 18`
- `RADIUS_XL = 24`
- `RADIUS_PILL = 999`

La primera version registra la intencion visual; futuras fases pueden extender mapas de layout para simular radius mas avanzado en widgets Tk.
