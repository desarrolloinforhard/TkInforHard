# v1.1.0 Scope

Release compatible orientada a mejorar experiencia visual, rendering y cargas largas.

Incluye:

- `IHLoader` corporativo con aro circular, iniciales IH visibles, render suavizado y texto opcional.
- `IHRenderHost` con loader minimo, cache, `min_loader_cycles`, `settle_delay` y preparacion asincronica.
- `IHBusyOverlay` para procesos largos dentro de pantallas.
- `IHAnimator` para microinteracciones tipo CSS.
- Cards mejoradas con seleccion, variantes semanticas y transiciones.
- Icon browser con `IHImageGridTable`.
- Contexto tecnico actualizado para futuros proyectos consumidores.

Compatibilidad:

- No introduce breaking changes.
- Proyectos consumidores pueden seguir usando APIs `1.0.0`.
- Para usar async loading, overlays o loader extendido, requerir `TkInforHard>=1.1.0`.
